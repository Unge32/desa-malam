Desa Malam is an original third-person survival-horror game: play Bara, a lone traveler trapped in the infected village of Wanasari, and survive seven nights of the Afflicted with scarce ammo, healing herbs, and a wandering merchant. Serve it with `node serve.ts` and open http://localhost:8080.

## Run it

```sh
node serve.ts
```
